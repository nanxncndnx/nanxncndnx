My personal website. Here I share my thoughts through blog posts, book reviews, and in-depth documentation on topics I'm passionate about: the loop, the boundaries of acceptance, zero and infinity, and the stories that are one of a kind.

## On the site

| | |
|---|---|
| **Posts** | Essays and notes, like *The Old Man and the Childhood Drawing* |
| **Books** | Book reviews |
| **Docs** | Longer write-ups, rendered as PDFs directly on the page |

## Featured

**[From the Loop to the Lever](https://github.com/nanxncndnx/from-the-loop-to-the-lever)**: a question, a game, a few mistakes, and an equation that came out of them. An unfinished adventure, with no claims.

## How it's built

The site lives in [`my-blog/`](my-blog), is styled with Tailwind CSS, renders PDF docs in the browser with pdf.js, and is deployed to GitHub Pages by the workflow in [`.github/workflows`](.github/workflows).
